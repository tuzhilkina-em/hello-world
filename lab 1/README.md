# Hello, World!

Самостоятельная работа по серверной разработке. При каждом запросе сервер Node.js формирует HTML и подставляет дату и время по Москве. Кнопка «Обновить время» отправляет новый запрос.

## Запуск

Установите Node.js и выполните:

```sh
node server.mjs
```

Откройте http://127.0.0.1:3000. Сторонние пакеты не требуются. Логотип загружается с [сайта Московского Политеха](https://mospolytech.ru/ob-universitete/brandbook/).
