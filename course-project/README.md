# Веб-практикум

Курсовой проект по серверной веб-разработке. PHP 8.1+, Flight PHP 3.19.5, PDO SQLite и mbstring.

## Запуск

```sh
composer install --no-dev
php -S 127.0.0.1:8080 router.php
```

Откройте http://127.0.0.1:8080/. Архив проекта уже содержит Flight PHP и его лицензию, поэтому из архива приложение можно запустить и без Composer.

## Что можно проверить

- Главная выводит московское время формирования ответа сервером.
- Каталог фильтруется по теме. Статья открывается по адресу `/articles/routing` и показывает никнейм автора из таблицы `users`.
- `/planner?hours=12&days=6` выводит 120 минут в день.
- `/feedback` принимает сообщение, валидирует его, сохраняет в SQLite и возвращает номер обращения. Сообщения через публичные страницы не выдаются.

Статьи и авторы загружаются из учебного набора в SQLite в памяти. Обращения сохраняются в отдельной файловой базе. Локально используется каталог `course-data` рядом с каталогом проекта. Для Apache файл `.htaccess` запрещает доступ к каталогу `.course-data`. Для другого сервера задайте `PRACTICE_DATA_DIR` с путём вне публичного корня.

Публикация на Apache требует `mod_rewrite`. Загрузите архив с библиотекой Flight в каталог сайта вместе с файлом `.htaccess`.
