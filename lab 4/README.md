# Лабораторная № 4. Домашняя работа с роутингом

Запустите локальный сервер из каталога проекта:

```sh
php -S 127.0.0.1:8080 router.php
```

Откройте http://127.0.0.1:8080/bye/Маша. Маршрут передаёт имя в метод
`GreetingController::sayBye(string $name)`, а страница выводит «Пока, Маша».

Для публикации на Apache перенесите файлы вместе с `.htaccess`. Для маршрута используется `mod_rewrite`. На хостинге в подкаталоге открывайте `/имя-каталога/bye/Маша`.
