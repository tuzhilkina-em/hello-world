# Лабораторная № 3. Записная книжка

PHP 8.1+ с PDO SQLite и SQLite 3.35+. Запуск из каталога работы:

```sh
php -S 127.0.0.1:8080
```

Вход через `/index.php`. PHP создаёт отдельную SQLite-базу для каждой сессии, поэтому посетители учебного сайта не видят чужие контакты. Локально базы хранятся в каталоге `contact-book-data` на уровень выше каталога работы. На Apache приложение создаёт каталог `.contact-book-data` с запретом HTTP-доступа через `.htaccess`. При необходимости задайте PHP переменную окружения `CONTACT_BOOK_DATA_DIR` с путём к доступному для записи каталогу вне публичного корня.

В форме обязательны фамилия и имя. Сортировка по дате помещает записи без даты в конец. Ссылка удаления отправляет POST через JavaScript. При отключённом JavaScript после перехода доступна кнопка удаления.
