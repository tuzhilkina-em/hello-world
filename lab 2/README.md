# Лабораторная работа 2. Feedback form

Форма отправляет POST-запрос напрямую на https://httpbin.org/post. Для проверки используйте вымышленные данные, поскольку сервис возвращает отправленные значения в ответе.

На второй странице PHP вызывает `get_headers()` для https://httpbin.org/get и выводит HTTP-заголовки в поле только для чтения.

## Запуск

В каталоге `lab 2` выполните:

```sh
php -S 127.0.0.1:8080
```

Откройте http://127.0.0.1:8080/. Для публикации нужен хостинг с PHP, включённым `allow_url_fopen` и исходящим HTTPS-доступом к httpbin.org. Загрузите содержимое каталога в корень сайта.
