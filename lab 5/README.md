# Лабораторная № 5. Домашняя работа с представлением

В шаблоне `view.php` элемент `<title>` использует переменную `$title`. Если переменная не передана, заголовок вкладки — «Мой блог».

- `/hello/username` показывает «Привет, username» и задаёт заголовок «Страница приветствия».
- Главная и `/bye/username` используют заголовок «Мой блог».

Запуск из папки работы:

```sh
php -S 127.0.0.1:8080 router.php
```

Откройте http://127.0.0.1:8080/hello/username. Для Apache загрузите файлы вместе с `.htaccess` и включите `mod_rewrite`.
