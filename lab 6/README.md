# Задание 3.1. Автор статьи

В `ArticlesController::show()` запрос к таблице `articles` возвращает статью с полем `author_id`. Затем отдельный запрос к таблице `users` получает `nickname`. Шаблон `view.php` выводит никнейм рядом с текстом «Автор».

Для примера `database.php` создаёт две связанные таблицы в SQLite в памяти и заполняет их учебными данными. Внешняя база для запуска примера не требуется.

Для локального запуска нужен PHP 8+ с PDO SQLite.

```sh
php -S 127.0.0.1:8080 router.php
```

Откройте http://127.0.0.1:8080/articles/1 или http://127.0.0.1:8080/articles/2.
